# RISC-V Parser

## Бизнес-логика приложения

Программа-транслятор (дизассемблер) преобразует машинный код из бинарных ELF-файлов в читаемый текст программы на языке ассемблера архитектуры RISC-V.

## Функционал приложения

При запуске утилита принимает ELF-файл и создаёт текстовый файл с дизассемблированным кодом:

1. Разбирает структуру ELF-файла и извлекает секции `.text` (исполняемый код) и `.symtab` (таблица символов).
2. Дизассемблирует машинный код в формате Little Endian. Поддерживает базовый набор целочисленных команд **RV32I** и расширение умножения и деления **RV32M**.
3. Использует имена регистров в формате **ABI**.
4. Разрешает адреса переходов: ищет метки в таблице символов, а если метка для адреса не найдена, создаёт её в формате `L%i` (`L0`, `L1`, `L2` и т. д.).
5. Выводит неизвестные машинные коды как `unknown_instruction`. Псевдоинструкции не распознаются.
6. Формирует выходной файл со строгим форматированием и разделяет секции `.text` и `.symtab` одной пустой строкой.

## Спецификации и стандарты

В качестве источника спецификации инструкций используется [RISC-V ISA Manual (release 6cd14db-2026-05-17)](https://github.com/riscv/riscv-isa-manual/releases/tag/riscv-isa-release-6cd14db-2026-05-17).

## Тесты

Для проверки парсера подготовлен бинарный файл `my_test.elf`. Он содержит все поддерживаемые программой инструкции RV32I и RV32M и используется в автотестах для проверки корректности трансляции.

## Примеры использования

Программа запускается из командной строки с указанием входного и выходного файлов:

```bash
./riscv_parser input_file.elf output_file.txt
```

Пример содержимого `output_file.txt` с восстановленными и созданными метками:

```text
.text
00010074    <main>:
   10074:   00000013        addi    zero, zero, 0
   10078:   00100137        lui     sp, 256
   100c8:   fcf42e23        sw      a5, -36(s0)
   100fc:   fea794e3        bne     a5, a0, L0

000100e4    <L0>:
   100e4:   00000013        addi    zero, zero, 0

.symtab
Symbol Value             Size Type    Bind    Vis       Index Name
[  0] 0x0                   0 NOTYPE  LOCAL   DEFAULT   UNDEF
[  1] 0x10074               0 SECTION LOCAL   DEFAULT       1
[  2] 0x112F8               0 SECTION LOCAL   DEFAULT       2
[  3] 0x0                   0 SECTION LOCAL   DEFAULT       3
[  4] 0x0                   0 SECTION LOCAL   DEFAULT       4
[  5] 0x0                   0 FILE    LOCAL   DEFAULT   ABS test.c
[  6] 0x11AF8               0 NOTYPE  GLOBAL  DEFAULT   ABS __global_pointer
```

### Формат вывода секции `.text`

Строки формируются по следующим шаблонам `printf`:

- **Инструкция с меткой:** `"%08x   <%s>:\n"` (адрес, метка).
- **Инструкция с тремя аргументами:** `"   %05x:\t%08x\t%7s\t%s, %s, %s\n"`.
- **Инструкция с двумя аргументами:** `"   %05x:\t%08x\t%7s\t%s, %s\n"`.
- **Инструкции load/store и jalr:** `"   %05x:\t%08x\t%7s\t%s, %s(%s)\n"`.

Константы (`immediate`) выводятся в десятичном формате (`dec`), а смещения переходов J* и B* (`offset`) — в шестнадцатеричном (`hex`). Строка инструкции без метки содержит адрес, полный машинный код, мнемонику и аргументы.

### Формат вывода секции `.symtab`

- **Заголовок таблицы:** `"Symbol Value             Size Type    Bind    Vis       Index Name\n"`.
- **Строка символа:** `"[%4i] 0x%-15X %5i %-8s %-8s %-8s %6s %s\n"`.
